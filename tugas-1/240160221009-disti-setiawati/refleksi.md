
# Refleksi Pertemuan 2
## JavaScript Modern (ES6+) dan Asynchronous JavaScript

### 1. Tiga hal yang paling mengubah cara saya menulis kode

**a. Arrow Function dan Template Literal**

Kedua fitur ini membuat penulisan kode menjadi lebih sederhana. Arrow function membantu menyingkat penulisan fungsi, sedangkan template literal memudahkan menampilkan informasi seperti nama mahasiswa, mata kuliah, dan status kehadiran.

**b. Array Method (map, filter, dan reduce)**

Array method sangat membantu dalam mengolah data absensi. Contohnya, filter digunakan untuk mengambil data mahasiswa yang hadir, map untuk menampilkan daftar mata kuliah, dan reduce untuk menghitung jumlah kehadiran.

**c. Async/Await dan Promise**

Async/await membantu menjalankan proses yang membutuhkan waktu secara lebih teratur. Dalam proyek ini, konsep tersebut digunakan untuk menjalankan fungsi CRUD pada data mahasiswa dan absensi. Promise.all() juga membantu menjalankan dua proses pengambilan data secara bersamaan.

### 2. Hal yang masih membingungkan

Saya masih perlu memahami lebih dalam cara kerja proses asynchronous, terutama ketika beberapa proses dijalankan secara bersamaan menggunakan Promise.all(). Saya juga ingin lebih banyak berlatih agar dapat memahami urutan proses dan hasil yang dikembalikan oleh setiap fungsi asynchronous.
